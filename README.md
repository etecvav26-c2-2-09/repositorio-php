## 📌 Sobre o Projeto

**GameZone** é um site voltado para a comunidade gamer, reunindo análises de jogos, notícias do universo gaming, dicas e fórum de discussão. O objetivo é ser o ponto de encontro digital para jovens que vivem e respiram games.

## 🎯 Proposta do Site

### Objetivo
Criar um espaço digital completo para a comunidade gamer brasileira, oferecendo conteúdo de qualidade sobre jogos, plataformas e cultura gamer.

### O que o usuário encontrará
- Análises e reviews de jogos
- Notícias e lançamentos
- Guias, dicas e walkthroughs
- Rankings e listas temáticas
- Fórum de discussão entre jogadores

### Problema que resolve
Muitos gamers precisam acessar vários sites diferentes para ter informações completas. O GameZone centraliza tudo em um único lugar, com foco no público brasileiro.

### Serviços oferecidos
- Conteúdo editorial sobre games
- Newsletter semanal
- Área de cadastro/perfil de usuário
- Fórum comunitário
- Formulário de contato para parcerias

## 📱 Mobile First

O projeto foi desenvolvido com a abordagem **Mobile First**, pois a maior parte do público acessa conteúdo pelo celular.

### Por que Mobile First?
- Mais de 70% dos jovens adultos acessam sites via smartphone
- A experiência no celular deve ser fluida e rápida
- Garante melhor performance e SEO

### Como o site se adapta para celular

| Elemento   | Adaptação Mobile                                      |
|------------|-------------------------------------------------------|
| **Menu**   | Menu hambúrguer (ícone ☰) com navegação lateral       |
| **Imagens**| Tamanho responsivo com `max-width: 100%`              |
| **Textos** | Fontes mínimas de 16px, parágrafos curtos             |
| **Layout** | Uma coluna no mobile, múltiplas colunas no desktop    |
| **Botões** | Mínimo de 44×44px para fácil toque                   |
